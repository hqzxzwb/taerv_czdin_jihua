# 泰如话学堂

线上地址：<https://tairu.ruilisi.com/>

面向零基础学习者（尤其是孩子）的泰如方言学习站。内容全部来自本仓库根目录的词条
（`a/`…`z/`）、单字音表（`daen_cz.csv`）和语法笔记；网站只做挑选、分级和练习，
不另造内容。词条更新后重新部署一次，网站就跟着更新。

## 泰如话在哪里说

泰如话（江淮官话泰如片）主要通行于江苏的泰州、兴化、姜堰、泰兴、东台、大丰、海安、如皋、如东一带。

以东台话为例：它通行于盐城东台市全境，以及相邻的大丰区南部、海安市东南角、兴化市东北角，使用人口约 120 万；
保留阴入、阳入两个入声调；境内沿范公堤分台城、堤东、堤西、街唐四片，各片声母韵母略有差别，但互相通话没有障碍。
（据[百度百科“东台话”](https://baike.baidu.com/item/%E4%B8%9C%E5%8F%B0%E8%AF%9D/8965743)）

### 一节课的流程

每课 5–8 个词，大约 5 分钟：

1. **认词**：三个一组出新词卡——汉字、拼音（按声调上色）、音标、普通话意思、调形图、词典里的真实例句。
2. **马上练**：每组学完立刻各考一题，趁热记住。
3. **综合练习**：选意思、选词、选拼音、辨声调、例句填空（用词典例句里的“～”做空）、连线配对、拼写。
4. **答错重来**：答错的题在本课末尾再出现一次。
5. **结算**：按错题数给一到三颗星，记分，本课的词自动进入复习卡片。

### 几条教学上的取舍

- **课程里不放词典里没有的东西。** `course.txt` 里每个词都要能在词典或单字表里按“写法 + 读音”对上，
  对不上时 `yarn data` 直接报错中止。普通话释义是为孩子写的简短版，完整解释点进词条看。
- **和普通话同形同义的词只练读音。** “吃饭”问“什么意思”等于白问，这类词只出选拼音、辨声调的题。
- **声调用颜色 + 调形图 + 哼唱三种方式呈现。** 目前没有真人录音：“听声调”播放的是浏览器合成的音高走向，
  只帮助抓住调子。参考调值以泰兴、如皋一带为准，页面上有说明。真人录音是下一步。
- **例句过滤。** 课程例句只取 5–26 字、含一个“～”的短句，并排除了不适合孩子的用字。
- **不用注册。** 分数、星星、连续学习天数、复习卡片都存在浏览器本地（`localStorage`），不上传。

### 改课程

`content/course.txt` 一行一个词：

```
U time|今朝明朝|📅|今天、明天、刚才、一会儿     ← 单元：id|标题|图标|介绍
L 哪一天                                          ← 课
今朝|gen1 do|今天                                 ← 词典词条：词|拼音|普通话意思
=一|ieh7|一                                       ← 单字表：=字|拼音|普通话意思
```

改完跑 `yarn data`，有对不上的词会逐条列出来。

## 二、对国内用户友好

- **服务器在国内**，HTTPS 证书自动签发续期。
- **不依赖境外资源**：页面不加载 Google Fonts、境外 CDN 或第三方统计，所有脚本和样式都由本站提供；
  字体用系统自带的中文字体。站内唯一的外链是指向本项目 GitHub 的出处链接，打不开也不影响使用。
- **手机优先**：手机上是底部五个标签（首页、学习、拼音、复习、词典），按钮高度不小于 48px；
  电脑上是顶部导航和多栏布局。
- **全中文界面**，说明文字按小学生能读懂的程度写。
- **不需要账号、手机号或微信登录**，打开就能学。

已知不足：扩展区的生僻字（如“𬥐”“𢻷”）在部分手机上可能显示成方框，目前没有内置补字字体。

## 三、开发

需要 Node 20+、yarn、python3。

```sh
cd web
yarn install
yarn data     # 从仓库根目录的 md/csv 生成 web/data/*.json
yarn dev
```

`yarn data` 复用根目录的 `generate_search.py`（词条解析）和 `ti_fan_ien_converter.py`（各地音标换算），
生成的 JSON 不进版本库。

目录：

```
web/
  app/           页面（Next.js App Router）
  components/    课程播放器、卡片、导航等
  lib/           数据读取与搜索、出题、学习记录、声调
  content/       课程源文件 course.txt
  scripts/       build_data.py
  bin/deploy.sh  发版脚本
  helm/          线上配置
```

## 四、部署

线上这一份跑在 Kubernetes 上。集群、镜像仓库、域名这些环境信息都放在本地文件里，不进版本库：

```sh
cd web
cp .deploy.env.example .deploy.env                  # 应用名、域名、镜像仓库、kubeconfig、chart 路径
cp helm/values.example.yaml helm/values.local.yaml  # 镜像地址、Ingress 域名和注解
bin/deploy.sh
```

脚本依次做：

1. `build_data.py` 重新导出数据（词条有更新就在这一步进来）
2. `yarn build`，产物是 Next.js standalone
3. `docker build --platform linux/amd64`，镜像只含 standalone 产物、静态文件和 `data/`
4. 推到 `$REGISTRY/$NAME:<git 短哈希>`
5. `helm upgrade -i $NAME $CHART_DIR -f $HELM_VALUES`
6. 进 pod 读 `.next/BUILD_ID`，和本地比对，一致才算成功

要求：本机能 `docker push` 到所填的镜像仓库；所用的 chart 接受 `image.repository`、`image.tag`、
`ingress` 和探针这几项配置。容器监听 80 端口，健康检查走 `/ping`。

不用 Kubernetes 也可以：`docker build` 出来的镜像直接 `docker run -p 80:80` 就能跑，没有数据库和其他依赖。
