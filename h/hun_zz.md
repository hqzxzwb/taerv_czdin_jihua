# 獾子
hun1 zz
+ 指如皋地区的人。
  * 如东方言词典
+ 哺乳动物，形如狗而足短，穴土而居，昼伏夜出，食果实、虫蚁。
  * 泰兴方言辞典
    + 体形显得很胖，故乡人谓肥胖者“养得个獾子啊似的”。

# 蚶子
hun1 zz
+ 蚶科动物魁蚶、泥蚶、毛蚶的总称。
  * 如东方言词典
+ 也指四角蛤蜊。
  * 如东方言词典
+ 软体动物，深潜海边滩涂沙泥中，清明前后肉质鲜嫩，味道最肥美，称之为“菜花～”，常呈簇状分布。
  * 东台方言词典

# 涵子
hun2 zz
+ 涵洞，道路与沟渠相交的设施，使水从路下流过的通道。
  * 东台方言词典
  * 泰县方言志
