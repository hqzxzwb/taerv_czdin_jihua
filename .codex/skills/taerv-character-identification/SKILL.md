# 辞书识字

辨认扫描原文中的汉字，确认字形及 Unicode 码位。

## 本地 OCR 与置信度

1. 汉字识别使用本地 OCR。查已有 OCR 和切图，复用能覆盖当前字的结果。需要新识别时使用已安装的本地工具，例如 RapidOCR 或 macOS Vision。
2. 结合原始识别文本、词框及工具提供的置信度核对字符，区分行置信度与逐字置信度；逐字置信度须与实际字符对应。
3. OCR 中低于 90% 的字符进入复看范围。先看清晰扫描：已认出的字结合扫描完成核对；尚未认出的字进入放大、切字和检字流程。置信度作为辅助信息。
4. 放大优先从 PDF 重新渲染，保留部件和笔画，避开邻字、标点、书脊阴影。上下文图用于确定词义、行序；单字图用于核对字形。跨栏、跨页时结合续文图核对上下文。
5. 需要进一步识别时，可换合适尺寸、识别范围或另一种本地 OCR。候选仍有分歧时，查字形与上下文。OCR 将疑字识成常见字时，继续核对扫描与候选结构。

RapidOCR 可能在文本检测、批识别和结果输出之间重新排序。提取解码器逐字概率时，按对应识别结果、框或稳定标识关联；直接将两份批列表按位置 `zip` 容易把别行分数贴到当前字上。先检查字序和结果对齐，再使用这些概率。

## 疑字检索与图形回查

拆字用于查实未认出的字。检字渠道使用字统。打开候选字页面，核对实际显示的字形、部件和码位。

按可见部件检索候选，结合部件相对位置、笔画和上下文筛选，再完成图形回查：

1. 将扫描原字与候选字形并排显示，保留清晰的上下文图。
2. 先核整体结构：上下、左右、包围等；再核各部件位置、朝向、交接和关键笔画。
3. 同一组部件排布不同的候选分别比较，逐一检查结构与关键笔画。
4. 简繁字、异体字分别对照扫描，确认实际字形及 Unicode 码位。显示字体须覆盖该码位；本地比较前可检查字体 `cmap`。
5. 把最终字符再次渲染，与扫描回看。字体风格和扫描噪声可容许差异，结构与部件位置须相合。

本地字体可用于候选图形对照。已有环境中的 HanaMinA、HanaMinB 分别覆盖部分基本区和扩展区字符，使用前检查本机路径及具体字形。

## 易错字对

### 刺（U+523A）与剌（U+524C）

- 看左框底角到中竖。“刺”（朿）在这里开口，“剌”（束）有下横相连。
- 下横右半断墨时，找左半的浅痕，并与同版清晰字形对照。

### 抬（U+62AC）与拾（U+62FE）

- 看右上部件斜笔与横笔的连接点：“抬”（厶）连接点在折角处；“拾”（合）下横连接在撇的笔画内，撇越过连接点继续向左下伸出。
- “抬”的“厶”上方开口，右上点与折笔分开；“拾”的“人”顶端相接。
